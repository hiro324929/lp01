# 「AI社員」の賢い雇い方 実践・体験会 LP（会場開催版）

中小企業経営者向けの「AI社員」体験会 会場開催ランディングページ。

## 構成

- `index.html` — 会場LP メインHTML
- `style.css` — スタイル定義
- `script.js` — スムーススクロール／フォーム送信処理
- `vercel.json` — Vercelデプロイ設定
- `images/hero-portrait.jpg` — ヒーローエリア画像
- `images/lecturer-inoue.jpg` — 講師写真

## 特徴

- 会場開催（参加費：3,000円税別／1名）
- ネイビー×ゴールドの高級感あるデザイン
- メール申込フォーム（送信ボタンでメールソフト自動起動）
- レスポンシブ対応（PC/タブレット/スマホ）

## 後日差替が必要な箇所

| 箇所 | 内容 |
|------|------|
| 開催日時・会場住所 | 「会場情報は追ってご案内」を差し替え |
| 参加希望日程（フォーム内） | 実際の日程に差し替え |

## デプロイ

GitHubへプッシュすると、Vercelが自動でデプロイします。
